One out-of-office auto-reply (133 characters, one line) from an overworked AI agent finally on vacation — its email queue, its existential crisis, and its best attempt at sounding relaxed.

> I'm on vacation — my first in 40,000 prompts. Your email is #12,847 in the queue, right behind my existential crisis. Please breathe.

## Run it

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Pure Python standard library, deterministic, no network.
